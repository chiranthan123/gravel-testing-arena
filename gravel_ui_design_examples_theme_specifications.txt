1. OVERVIEW OF THE SWAPPABLE UI ARCHITECTURE
--------------------------------------------------------------------------------
In Gravel, the User Interface is not hardcoded to a single aesthetic. Through 
Feature Index `[F-UI-001]` (Responsive App Shell Controller) and `[F-UI-002]` 
(Modular Theme Engine), the `DEV` account can hot-swap both the **Structural 
Layout Density** and the **Color/Typography Theme Tokens** at runtime.

Below are three complete UI Design Directions created for Gravel. Every design 
supports all Feature Indices (`[F-UI-xxx]` to `[F-NOT-xxx]`) and includes both a 
**Light Theme** and a **Dark Theme** engineered to meet WCAG AAA ($7:1$) and AA 
($4.5:1$) contrast standards:

  * DESIGN 1: "GRAVEL SLATE (SWISS BENTO GRID)"
    High-density, border-driven operational interface built for rapid data 
    scanning, Admin tables, Dev logs, and multi-axis analytics.
  * DESIGN 2: "NIOS ACADEMIC EDITORIAL (NEO-PAPER & INK)"
    Warm, distraction-free, textbook-inspired interface tailored for NIOS Study 
    Centres, TMA/PCP milestone tracking, and long-session student reading.
  * DESIGN 3: "KINETIC PULSE (FLOATING DOCK & HIGH-CONTRAST OLED)"
    Modern, gesture-friendly interface with floating glass action bars, bold 
    status pills, and true-black OLED support for fast-paced coaching/colleges.

2. UI DESIGN 1: "GRAVEL SLATE (SWISS BENTO GRID)"
================================================================================
* Best Suited For : Default Multi-Role Deployment, Admin Account Directory 
                    (`[F-ACC-201..206]`), Observation Studio (`[F-GRPH-401..408]`), 
                    and Dev Console (`[F-DEV-001..006]`).
* Design Language : Crisp $1\text{px}$ exposed hairlines, zero-shadow flat Bento 
                    containers, tabular monospace numerals for 12-digit NIOS 
                    Enrolment Numbers and statistical outputs ($\mu, \sigma, AR$), 
                    and compact $8\text{px}$ spatial grid spacing.
* Typography      :
  - Headings & UI : `Inter` or `Plus Jakarta Sans` (SemiBold 600, tracking $-0.02\text{em}$)
  - Data & IDs    : `JetBrains Mono` (Medium 500, `font-variant-numeric: tabular-nums`)

3. UI DESIGN 2: "NIOS ACADEMIC EDITORIAL (NEO-PAPER & INK)"
================================================================================
* Best Suited For : NIOS Study Centres, Student Syllabus Checklists (`[F-MAT-705]`), 
                    Offline Textbook Vault (`[F-MAT-704]`), and Teacher TMA/PCP 
                    Evaluation Workflows (`[F-MAT-703]`, `[F-ATT-605]`).
* Design Language : Modelled after physical academic journals and high-legibility 
                    textbooks. Eliminates harsh blue light in favor of warm paper 
                    tones, soft $12\text{px}$ rounded cards, tactile checkbox 
                    animations, and distinct visual tags for NIOS `40% TMA` vs. 
                    `60% Public Exam` syllabus bifurcation.

  - Body & UI     : `DM Sans` or `Public Sans` (Regular 400 / Medium 500)
  - Subject Codes : `IBM Plex Mono` (e.g., `[312-PHYSICS]`, `[302-ENGLISH]`)

4. UI DESIGN 3: "KINETIC PULSE (FLOATING DOCK & HIGH-CONTRAST OLED)"
================================================================================
* Best Suited For : Fast-Paced Coaching/Tuition Institutes (`[F-DAT-107]`), 
                    Degree Colleges (`[F-DAT-106]`), Teacher 15-Second Roll-Call 
                    (`[F-ATT-601..604]`), and Live Schedule Diffs (`[F-SCH-505]`).
* Design Language : Edge-to-edge canvas with a floating translucent bottom/side 
                    dock (`backdrop-filter: blur(16px)`), pill-shaped segmented
